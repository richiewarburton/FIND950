# FIND950 brand assets

The application icon is the approved FIND950 artwork from the 950TOOLS brand
asset pack dated 2026-08-11. It uses the three horizontal blue bars defined for
FIND950 in that pack.

- `FIND950.icns` — compiled macOS application icon; and
- `AppIcon.iconset/` — the complete matching macOS iconset.

Placeholder artwork is not retained in the live resource directory. The
approved pack is the only source for application identity assets.
